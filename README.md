# Taamerat360 — Business, connected.

Independent Vercel preview for Taamerat360's interactive website concept.

## Implemented
- Responsive homepage, FIND → CONNECT → DELIVER journey
- Four local SVG scene illustrations (no third-party illustration hosts)
- Scroll-driven scene selection, animated connector path, transitions, and pointer micro-parallax
- Accessible numbered controls (including arrow keys), pause/resume motion and reduced-motion support
- Business-challenge selector, four packages, eleven-industry explorer, responsive menu and skip link

## Development
This is a static HTML/CSS/JS site. Serve locally with a static HTTP server, e.g. run python3 -m http.server 8000, and open http://localhost:8000.

GitHub main deploys to the separate Vercel project taamerat360-preview. The original ChatGPT-hosted site is unchanged.
